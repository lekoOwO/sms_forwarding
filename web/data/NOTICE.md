# MCC/MNC data notice

The adjacent `mcc-mnc-list.json` file is a snapshot from [pbakondy/mcc-mnc-list](https://github.com/pbakondy/mcc-mnc-list).
The snapshot is pinned in `mcc-mnc-list.metadata.json`.

The source project code uses the MIT license.
The source project states that the records come from the [Wikipedia Mobile country code page](https://en.wikipedia.org/wiki/Mobile_country_code).
The underlying Wikipedia data uses the [Creative Commons Attribution-ShareAlike 4.0 license](https://creativecommons.org/licenses/by-sa/4.0/).

The generated operator table keeps valid named MCC/MNC records, selects the source brand when available, and joins duplicate source brands.
The formatter adds the local `46697` translations for Traditional Chinese and Simplified Chinese.
